Quick Guides

Install Fabric

1. Download Fabric Installer
2. Run it and select your Minecraft version
3. Launch the new profile

Install Mods

1. Get Fabric API + your mods from Modrinth
2. Put .jar files in the mods folder
3. Restart the game

Performance Tips

• Use Sodium + Lithium + Starlight
• Lower render distance if needed
• Allocate 4–6 GB RAM max
