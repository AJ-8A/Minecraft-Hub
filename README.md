# Minecraft Hub

**Fully responsive** Minecraft resources website — works great on both **PC and mobile**.

## Live Preview
Open the `index.html` file in any browser or enable GitHub Pages to host it.

## Features
- Clean dark Minecraft-inspired design
- Fully mobile-friendly (responsive grid + flexible navigation)
- Quick links to popular servers, mods, shaders, tools & guides
- Zero dependencies — pure HTML + CSS

## How to use
1. Clone or download this repo
2. Open `index.html` in your browser
3. (Optional) Enable GitHub Pages in repo settings → Pages → Deploy from main branch
